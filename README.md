# mango_noctalia_config

Configuration files for mangowm with noctalia shell

## Folders and destinations

The following folder are included:

```
aida       --->   /etc/aida
mango      --->   ~/.config/mango
noctalia   --->   ~/.config/noctalia
```

### aida

The files in the aida folder contains the declarative definition of the system for use of mangowm and noctalia with aida (atomic immutable declarative archlinux). 

See https://github.com/allmun/aida for more information about aida.

### mango

The files in the mango folder contains my configuration files for mangowm.

It's my personal alternative to https://github.com/DreamMaoMao/mango-config.

### noctalia

The files in the noctalia folder contains my configuration files for the noctalia shell.

See https://noctalia.dev/shell for more information about the noctalia shell.
